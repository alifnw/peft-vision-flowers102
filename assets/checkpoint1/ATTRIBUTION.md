# Dataset images and audit snapshot

Images originate from Oxford Flowers102 by Maria-Elena Nilsback and Andrew Zisserman, accessed through the pinned XiN0919 VTAB-1k mirror. This small selection supports academic analysis of the project. It is not the complete dataset.

- Original dataset: https://www.robots.ox.ac.uk/~vgg/data/flowers/102/
- Mirror: https://huggingface.co/datasets/XiN0919/VTAB-1k
- Mirror revision: a1c257fbbeebd3260c0a201fe6a6c9916b56eee7
- Image paths, labels and SHA-256 hashes: input/dataset_audit.json

The mirror does not establish an umbrella license for all VTAB component datasets. Original component access conditions continue to apply. No new license is asserted over dataset photographs. Project charts and diagrams are generated from the stored analysis.
